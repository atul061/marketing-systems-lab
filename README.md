# Marketing systems lab

Small, practical tools and templates for marketing operations. Built to make campaign work more consistent and easier to measure.

## Starter tool: UTM link builder

[Open the UTM link builder](https://atul061.github.io/marketing-systems-lab/) to add source, medium, campaign, content, and term parameters to a landing-page URL. The tool runs in your browser and does not send entries to a server.

Example: a PMP launch Instagram reel might use `utm_source=instagram`, `utm_medium=organic_social`, and `utm_campaign=pmp_2027_launch`. Use one naming convention across channels so reporting stays clean.

## How this repository works

- `index.html`: the standalone UTM tool.
- Future tools will each include a short problem statement, usage instructions, and a metric they help improve.
- Changes are recorded as commits, making it easy to see what changed and when.

**Data note:** use sample or approved public information in this repository. Keep lead lists, budgets, credentials, CRM exports, and unpublished company material out of public repositories.
